# Реальная лаборатория и 3D: этап 2026-11-07

Цель создана в Codex по поручению пользователя, переданному из Ansible. Предыдущие критерии и результаты остаются в docs/PLAN.md и docs/VERIFICATION.md.

1. Ревизия: v1.0 использует один настоящий брокер, фиксированные команды и отдельную учебную 3D-модель. Не хватает редактирования, состояния реплик и полного цикла упражнения.
2. Исследование: официальные Apache Kafka 4.2 Docker, Admin/Producer/Consumer API, offsets и replication. Решения и границы в docs/LAB-WORKSPACE.md.
3. Изолированный трёхброкерный стенд, ограниченный редактор JSON, серверная валидация, Java-клиент из поставки Kafka, журнал и черновики в SQLite.
4. Упражнения: доставка и commit; повторное чтение без commit; отказ брокера и восстановление реплик. Независимая проверка читает Kafka заново.
5. Выразительная 3D-сцена показывает фактический снимок, отдельно воспроизводит сохранённые шаги. Доступны статический вид, пауза и reduced motion. Модель из песочницы не выдаётся за реальные метрики.
6. Проверки: unit/integration, браузер 320/390/768/1440, клавиатура, console, overflow, фон/невидимость; production build; настоящий стенд, ошибки без зачёта, восстановление и повтор.
7. GitHub CI, документация доказательств, выпуск 1.1.0 и открытое приложение. Завершение только после фактической проверки.

Тяжёлые локальные suites выполняются последовательно под общим .qa/trainer-hardware.lock. Чужие ресурсы, данные и порты не изменяются. Незавершённые задачи других этапов не удаляются.
