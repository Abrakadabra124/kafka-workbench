## Проверки

- Статический независимый review исправил адреса карточек, повторное прибытие старых событий при возвращении сцены и недостаточный контраст текста на начальном stop градиента.
- В CI первый прогон обнаружил три группы контрастных подписей. Они исправлены без отключения правил axe. Следующий прогон существующего браузерного набора и axe для всех ключевых маршрутов прошёл.
- Новые CI проверки покрывают три причинные модели, составные неверные действия, reset, адресные переходы, keyboard actions, finite arrival, возврат в viewport, reduced motion и переключение partition на 320 px.
- TypeScript, обычные тесты и production build проверяются отдельно от настоящих Kafka tests. Реальные отказы и восстановления задокументированы в [PRACTICE-VERIFICATION.md](PRACTICE-VERIFICATION.md).

Первый локальный CUA проход выполнен под общим browser lock на отдельной QA-базе. Проверены действия gallery и пауза, повторная доставка в песочнице, ошибочный ответ и сохранение заметки, три причинные модели (fault, неверное решение без зачёта, repair, verify), prepare/cancel и фокус, меню/Escape и сохранение выбранного task после reload. Console errors и warnings отсутствовали. Пользовательский прогресс на 4184 сохранил прежний SHA-256 ответа API. Первоначальная проверка overflow относительно innerWidth впоследствии уточнена: она не учитывала место классического scrollbar.

Дополнительное требование пользователя о полном интерьере выполнено отдельной композицией рабочих страниц. [Инвентарь и сравнение по маршрутам](INTERNAL-SCREEN-REVIEW.md) описывает рабочие колонки, расположение действий, typography кода/журналов и встроенные подтверждения. Два независимых рецензента просмотрели 17 фактических JPG. Их замечания к mobile notice, порядку расследования, плееру, каталогу источников и начальному статусу модели исправлены.

CUA повтор охватил 28 сочетаний семи внутренних маршрутов и ширин 1440/768/390/320 px. Подтверждение подготовки рядом с кнопкой получает фокус, отмена возвращает его; начальная внешняя система модели работает. На окне высотой 400 px сцена расследования находится на y=802.42 и имеет состояние offscreen. После повторного просмотра console errors/warnings отсутствуют, пользовательский progress hash не изменён. Снимки обновлены, viewport восстановлен, пользовательская вкладка открыта на основном порту 4184, browser lock освобождён.

Последнее независимое ревью обнаружило небольшой горизонтальный scroll на 320 px, который сравнение с innerWidth пропускало. Удалён `body min-width: 320px`; assertions используют clientWidth и дополнительно покрывают 305 px доступного содержимого. Заключительный CUA повтор подтвердил во всех восьми маршрутах и открытом подтверждении clientWidth=scrollWidth=305 px при окне 320 px, без console errors/warnings. Исходные измерения и окончательные результаты сохранены раздельно в [INTERNAL-SCREEN-REVIEW.md](INTERNAL-SCREEN-REVIEW.md).

Итоговый код `fad56c2dca9fe509da537b580ab96f95a2e6b1d1` прошёл [полный CI](https://github.com/Abrakadabra124/kafka-workbench/actions/runs/43287655221): все четыре jobs SUCCESS. Независимый просмотр восьми финальных внутренних экранов, четырёх заполненных реальных CI-снимков и последнего сравнения scrollbar не оставил блокирующих замечаний. Плотная подпись consumer на узком экране остаётся косметическим ограничением; полное состояние доступно в соседних текстовых показателях и описании сценария.

## Границы

CSS 3D используется вместо дополнительной WebGL-зависимости: задача требует ограниченного числа предметов, читаемых данных и доступных элементов управления. Это не физический рендерер. Партиции overview не выдаются за brokers. Простая учебная hash-функция не равна partitioner Java-клиента Kafka.

Новая gallery не содержит фонового генератора событий и таймеров телеметрии. Данные изменяются от действий пользователя. `useSceneMotion` учитывает reduced motion, visibilitychange и IntersectionObserver; история настоящего стенда остаётся воспроизведением сохранённых измерений. UI не заявляет нагрузочный benchmark, производственную observability или SaaS-многопользовательскую изоляцию.
