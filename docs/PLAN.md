# Kafka Workbench: критерии выпуска

Дата: 2026-10-07. Персональный русскоязычный тренажёр с публичными исходниками.

1. Исследовать местные тренажёры и первичные источники Kafka, сравнить подходы.
2. Реализовать 18 уроков в 6 модулях с теорией, вопросом, инженерной ситуацией, объяснениями и источниками.
3. Проверять ответы на сервере, сохранять прогресс и заметки в SQLite. Открытие урока не даёт баллов.
4. Сделать управляемую визуальную модель: partition routing, независимые группы, read/commit/restart, lag, ребалансировка. Явно описать упрощения.
5. Предоставить настоящую лабораторию Apache Kafka 4.2.2 в Docker: запуск, топик, запись, чтение, инспекция, удаление своих ресурсов.
6. Проверить негативные сценарии API, инварианты модели, браузерное прохождение, сохранение, клавиатуру, мобильный экран, доступность и production-сборку.
7. Опубликовать отдельный публичный GitHub-репозиторий, проверить CI и чистое клонирование.
8. Дополнение пользователя от 2026-10-07: добавить отдельный раздел повседневных инженерных проблем с управляемой анимацией и визуализацией. Шесть кейсов Kafka: отставание группы, некорректное событие, advertised.listeners, недостаточный ISR, заполнение диска, дубли внешних операций. Требовать наблюдения, диагностику, исправление и отдельную проверку восстановления; сохранять результат на сервере, проверять ошибочные действия и восстановление.
9. По прямому поручению пользователя передать этот пункт в цели всех чатов проекта «Тренажёры». Сообщения направлены в существующие чаты Terraform, troubleshooting, PostgreSQL, Ansible, Jenkins, Python и Kubernetes. Их реализация ведётся в соответствующих репозиториях, независимо от выпуска Kafka.

Дизайн: белый основной фон, прохладная серая боковая навигация, Inter, акцент #e34825, тонкие разделители, нативные схемы потоков. Главный экран по design/concept.png. Дополнительные экраны нужны для рабочего учебного цикла, используют те же типографику и компоненты.

Граница: локальный персональный продукт; один профиль на установку. Лаборатория с одним брокером не доказывает отказоустойчивость, симулятор не является Kafka. Уровень bigtech означает ориентир для инженерных критериев, не подтверждённый статус продукта. Публичный многопользовательский SaaS, SLA и нагрузочные гарантии не входят в этот выпуск.
